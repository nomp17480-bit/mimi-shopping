# Mimi Shopping

متجر إلكتروني جزائري للحقائب، مبني باستخدام **Next.js App Router** و**Supabase**، بواجهة عربية متجاوبة ولوحة إدارة.

## الحالة الحالية

- التطوير المعتمد على فرع `mimi-upgrade`.
- معاينة Vercel الأخيرة: [فتح المتجر](https://mimi-shopping-j9hh3ia0u-nomp17480-7979.vercel.app/).
- آخر تعديل منشور على المعاينة: `bfc6f803fbf113ab09388bd9189dd7d7f5854d13`.
- قاعدة البيانات الأساسية وتفعيل المتجر وسياسات الأدوار وتقوية checkout تم تطبيقها والتحقق منها.
- الدفع المتاح حالياً: الدفع عند الاستلام فقط.
- أسعار التوصيل تبقى غير مفعّلة إلى أن تُدخل الأسعار الحقيقية من لوحة الإدارة.
- بيانات المنتجات والصور وروابط التواصل قابلة للإكمال لاحقاً من لوحة الإدارة.

## الوظائف الموجودة

- واجهة متجر وفئات ومنتجات وسلة.
- صفحة إتمام الطلب مع اختيار الولاية والبلدية وطريقة التوصيل.
- API آمن لإرسال طلبات الدفع عند الاستلام إلى دالة قاعدة البيانات.
- تحقق خادمي من بيانات العميل والولاية والبلدية والمخزون ورسوم التوصيل.
- لوحة إدارة للمنتجات والفئات والمخزون والطلبات والشحن وإعدادات التواصل والفريق.
- رفع صور المنتجات إلى Supabase Storage مع تقييد الصلاحيات حسب الدور.

## إعدادات التشغيل

متغيرات البيئة المطلوبة في Vercel:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` (أو المفتاح العام القديم `NEXT_PUBLIC_SUPABASE_ANON_KEY`)

لا تضع مفتاح `service_role` في متغيرات عامة أو في كود المتصفح، ولا ترسله في المحادثات.

## قواعد العمل الآمنة

- لا تعد تشغيل `supabase/bootstrap.sql` أو `supabase/activate_store.sql` أو خطوات 004 و005 التي سبق تطبيقها.
- لا تحذف أو تعدّل بيانات Supabase الحية أثناء أعمال الصيانة.
- لا تدمج إلى `main` ولا تنشر Production دون موافقة صريحة.
- جميع التعديلات الحالية تكون على `mimi-upgrade` ومعاينات Vercel فقط.

## ما بقي قبل الإطلاق الفعلي

1. إدخال أسعار التوصيل الحقيقية للولايات التي ستُخدم وتفعيلها من لوحة الإدارة.
2. ربط النطاق التجاري عند جاهزيته.
3. إجراء طلب COD حقيقي مضبوط بعد تهيئة سعر توصيل واحد على الأقل، مع التحقق من الطلب والمخزون.
4. مراجعة نهائية قبل أي نشر Production.
